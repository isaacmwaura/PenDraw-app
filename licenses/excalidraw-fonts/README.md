# Fonts distributed with the Excalidraw engine

PenDraw copies the unmodified font files supplied by `@excalidraw/excalidraw` 0.18.1 so desktop and browser sharing can load them locally. Font notices and licenses remain separate from PenDraw's MIT license.

| Font | Copyright notices and license text |
|---|---|
| Assistant | Assistant-OFL.txt |
| Cascadia Code | Cascadia-OFL.txt |
| Comic Shanns | ComicShanns-notices.txt (MIT text included) |
| Excalifont | Excalifont-notices.txt (SIL Open Font License text included) |
| Liberation Sans | Liberation-OFL.txt |
| Lilita One | Lilita-OFL.txt |
| Nunito | Nunito-OFL.txt |
| Virgil | Virgil-LICENSE.txt |
| Xiaolai | Xiaolai-notices.txt; SIL Open Font License 1.1 text is also included in Assistant-OFL.txt |

Engine font sources: https://github.com/excalidraw/excalidraw/tree/v0.18.1/packages/excalidraw/fonts

Additional license sources: https://github.com/microsoft/cascadia-code/blob/main/LICENSE, https://github.com/liberationfonts/liberation-fonts/blob/main/LICENSE, https://github.com/google/fonts/blob/main/ofl/lilitaone/OFL.txt, https://github.com/google/fonts/blob/main/ofl/nunito/OFL.txt and https://github.com/excalidraw/virgil/blob/main/LICENSE.md.
